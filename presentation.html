01 — The Problem
You see it.
You can't find it.
01
Clothes in inspiration photos are often seasonal, sold out, or unlabeled.
02
Keyword search fails when you can only describe a visual style.
03
"Beige oversized linen blazer with subtle texture" rarely returns what you saw.
04
No easy way to go from a visual inspiration to a similar item you can buy.
02 — The Solution
Search with an image,
not a description.
1
Upload a clothing photo — Pinterest screenshot, your own photo, anything.
2
FashionCLIP encodes the image into a 512-dimensional visual embedding.
3
FAISS searches 20,000+ DeepFashion items by cosine similarity.
4
Style preferences (color, fit, goal) rerank results using text-image similarity.
Scoring Formula
final_score = similarity + α · goal_bonus + α · color_bonus − α · avoid_penalty
03 — Tech Stack
Built entirely on open-source tools.
Web App

Embedding Model

Vector Search

Reranking
Text Embeddings
FashionCLIP text encoder · weighted scoring formula
Background Removal
